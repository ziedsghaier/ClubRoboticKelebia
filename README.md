# 🤖 ISET Kelibia Robotics Club Website

Welcome to the official repository for the **ISET Kelibia Robotics Club** website! This web application serves as the central hub for club members, prospective students, and robotics enthusiasts to explore projects, stay updated on upcoming workshops, and get involved in our community.

---

## ✨ Features

- 🚀 **Home & Announcement Banner:** Highlights key upcoming events, hackathons, and announcements.
- 🛠️ **Project Showcase:** Interactive gallery showcasing autonomous robots, IoT hardware builds, and competition prototypes.
- 📅 **Events & Workshops:** Calendar and schedule for upcoming training sessions, Arduino/Raspberry Pi workshops, and coding jams.
- 📝 **Member Registration:** Simple signup form for new students to join the club.
- 💬 **Contact & Socials:** Direct links to club social channels, location at ISET Kelibia, and inquiry forms.
- 📱 **Fully Responsive:** Seamlessly optimized for desktop, tablet, and mobile devices.

---

## 🧰 Tech Stack

- **Frontend:** HTML5, CSS3 (Tailwind CSS), JavaScript (ES6+)
- **Icons & Assets:** Lucide Icons / FontAwesome
- **Hosting & Deployment:** GitHub Pages / Vercel

## 🚀 Getting Started

Follow these simple steps to set up and run the project locally.

### Prerequisites

- A modern web browser (Chrome, Firefox, Edge, Safari)
- Git installed on your system
- *(Optional)* [Live Server extension](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) for VS Code

### Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/your-username/iset-kelibia-robotics-website.git
   cd iset-kelibia-robotics-website
   ```

2. **Open with Live Server (or direct file open):**
   - Open the folder in VS Code.
   - Right-click `index.html` and select **Open with Live Server**.
   - Alternatively, double-click `index.html` to view it in your browser.
